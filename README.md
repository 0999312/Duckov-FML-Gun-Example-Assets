# Duckov-FML-Gun-Example-Assets
Unity Assets Project for Duckov FML Gun Example  
Code in https://github.com/0999312/Duckov-FML-Gun-Example  

本仓库是《鸭科夫武器示例模组》的资源仓库，用于存放和配置具体枪械和其他物品的资源文件。  
本仓库使用Unity版本为2022.3.6f2。  
可直接Build Assets Bundle，具体使用方法请配置好Unity项目之后自行查阅文件。
